                                              Probes#

                                              Detailed documentation for each monitoring probe type supported by SenHub Agent.

                                              System (Free)#

                                              • CPU - Processor utilization and load
                                              • Memory - Physical memory and swap usage
                                              • Network - Network interface bandwidth and errors
                                              • Logical Disk - Disk space, I/O, and filesystem health

                                              Infrastructure (Pro)#

                                              • Veeam - Veeam Backup & Replication v13 monitoring
                                              • Citrix - Citrix Virtual Apps and Desktops monitoring
                                              • NetScaler - Citrix ADC / NetScaler monitoring
                                              • Redfish - Hardware monitoring via Redfish API (Dell iDRAC, HPE iLO)
                                              • Syslog - Syslog message collection (UDP/TCP)
                                              • Event - Custom event collection via HTTP

                                              Network (Pro)#

                                              • Ping WebApp - Web application availability (ICMP)
                                              • Load WebApp - Web page load time measurement
                                              • Ping Gateway - Default gateway connectivity

                                              Advanced#

                                              • WiFi Signal - Wireless signal quality (Pro)
                                              • OpenTelemetry - OTLP metrics, traces, and logs (Enterprise)
